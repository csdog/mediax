# 实施状态

## 多平台本地发布（2026-10-13）

创作页支持文章、动态、视频和音频。可发布类型见 `src/shared/content.ts`。发布仍走应用内账号浏览器。正文保持纯文本和 Markdown 导入，支持本机定时发布、日历和发布结果汇总。Agent 控制面与 CLI 已接通，见 [control-api.md](control-api.md)；Public API / n8n / MCP 等后续计划见 [TODO.md](TODO.md)。

## 断网与休眠恢复（2026-10-21）

发布服务在首屏恢复后的 Eventually 阶段启动排期和网络检查；每 5 秒检查系统联网状态，并在领取目标和点击发布前再次检查。断网或系统休眠时不启动新目标，等待中的任务仍保留为 `pending`。联网或唤醒后自动继续等待中的目标；唤醒立即补查过期排期，仍未联网则继续等待。账号检查暂时占用浏览器时保留任务，下次检查再尝试。

执行中的流程会记录中断，即使连接已恢复或系统已唤醒，也阻止旧准备流程继续点击发布。流程返回或报错时，尚未点击的目标转为 `awaiting_user`，检查账号浏览器后手动继续；可能已经点击且无法核验的目标转为 `unknown`，仅核验、不自动重发。已经成功、明确失败或等待人工处理的目标均不会因联网或唤醒自动重试。退出时停止检查并移除电源事件监听。

使用 Electron 官方的 [联网检测](https://www.electronjs.org/docs/latest/tutorial/online-offline-events) 与 [电源事件](https://www.electronjs.org/docs/latest/api/power-monitor)。联网状态只反映系统网络可用性，不保证目标站点可达；站点超时仍按现有失败或待核验流程处理。离线单元测试模拟断网、准备/点击阶段休眠、唤醒补查排期、浏览器占用和重复启动/清理，未切断用户网络或让真实设备休眠，未发布真实内容。

## 发布方案（2026-10-21）

创作页「发布方案」可保存、应用和删除当前内容类型的方案，复用已选账号及发布身份、静默发布、并发数和上传限速。方案通过本机设置持久化，重启后保留。应用时使用当前身份名称；账号、身份失效或平台不再支持当前内容类型时阻止应用，避免选错目标。方案不保存标题、正文、素材、平台单独内容或具体定时时间，应用后仍需确认发布。

单元测试覆盖数据库重开、删除、重复名称与无效输入；界面测试覆盖保存、应用、删除、内容类型筛选、身份失效与设置保存失败。

## 账号资料与站点入口（2026-10-30）

56 个平台的默认入口、所属域名和 tab 图标回退统一维护在 `src/shared/platformSites.ts`。TikTok、Instagram、Threads、X、LinkedIn、Pinterest、Reddit、百家号、企鹅号和虎扑改从工作台或站点首页进入；支付宝生活号和简书对齐已有发布适配器入口。按完整域名边界匹配站点，并优先匹配小红书商家/私信版、腾讯视频和 QQ 音乐等专用域名。图标下载失败会尝试站点的下一候选，未知站点保持通用图标。

进一步核对公开官网，修正蜂网（原来指向无关域名）、爱奇艺号、微视、多多视频、大鱼号、AcFun、得物、皮皮虾、搜狐视频、蜻蜓 FM、荔枝 FM 和 Google Business 的创作/管理入口，并保留官方迁移前域名的站点识别。依据包括[蜂网官网](https://o.fun.tv/)、[爱奇艺创作平台](https://creator.iqiyi.com/)、[多多后台](https://live.yangkeduo.com/)、[得物官网的创作者入口](https://www.dewu.com/)、[蜻蜓 FM 的主播入口](https://www.qtfm.cn/)和[荔枝主播后台](https://nj.lizhi.fm/)。无法公开访问的入口保留待实测，不根据一次网络超时猜测新地址。

账号资料只从当前登录身份接口或账号控件读取。B 站和知乎读取当前用户接口；微博使用会话接口、当前页面账号状态及头像补取；头条、小红书、视频号保留各自创作后台识别；YouTube、Reddit、X、抖音、快手读取自己的账号区域；其他平台仅使用受限的账号菜单/后台头部用户信息区。移除整页猜测头像及用平台名冒充发布身份的回退。没有可靠用户区域的平台返回未识别，需要登录后的实际页面补充专用适配，不能认为已验证接入。

真实昵称和已保存发布身份名称一起更新，避免旧身份覆盖新昵称。历史通用探测产生的头像缓存需重新识别。无登录 Cookie 的平台必须读到当前用户信息，不能仅凭访问公开首页判为已登录。离线测试逐一覆盖全部平台的入口、域名/登录页边界及拒绝内容作者头像，并覆盖跨平台图标、头像失败、身份持久化与缺少登录资料。

本机已用既有会话复核 B 站、知乎、头条的身份资料；小红书当前显示未登录。其他未登录或未添加账号的平台尚无登录后实测结果，不能用上述离线测试代替。

## Facebook 本地发布（2026-10-13）

已接通主进程发布适配器和 SQLite 队列，编辑器可勾选个人主页与公共主页、预览并确认后发布。图片先复制到 userData/task-assets，任务固定正文、素材和目标身份。

- 每账号独立 Electron partition；通过 webContents 的 CDP target ID 精确查找 Playwright Page，不依赖 context/page 数组位置。
- 身份发现通过真实 Facebook 身份菜单切换、读取新页面 actor ID，并与本地会话身份比对。目标列表绑定登录账号所有者并本地保留；检查后恢复原身份。
- 发布前和点击前校验数字身份、正文和上传状态。遇到登录、验证码、同名身份歧义、已有不同草稿时暂停人工处理。
- 全局串行，各目标分别记录状态、attempt 和永久链接。明确失败才允许重试；已提交或结果未知仅提供核验入口。
- 核验会打开永久链接检查作者、正文和图片。未获取链接时保持待核验；用户可提供本次帖子的链接，不自动重复提交。
