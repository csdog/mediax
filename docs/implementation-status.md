# 实施状态

## 多平台本地发布（2026-10-13）

创作页支持文章、动态、视频和音频。可发布类型见 `src/shared/content.ts`。发布仍走应用内账号浏览器。正文保持纯文本和 Markdown 导入，不含定时发布。

## Facebook 本地发布（2026-10-13）

已接通主进程发布适配器和 SQLite 队列，编辑器可勾选个人主页与公共主页、预览并确认后发布。图片先复制到 userData/task-assets，任务固定正文、素材和目标身份。

- 每账号独立 Electron partition；通过 webContents 的 CDP target ID 精确查找 Playwright Page，不依赖 context/page 数组位置。
- 身份发现通过真实 Facebook 身份菜单切换、读取新页面 actor ID，并与本地会话身份比对。目标列表绑定登录账号所有者并本地保留；检查后恢复原身份。
- 发布前和点击前校验数字身份、正文和上传状态。遇到登录、验证码、同名身份歧义、已有不同草稿时暂停人工处理。
- 全局串行，各目标分别记录状态、attempt 和永久链接。明确失败才允许重试；已提交或结果未知仅提供核验入口。
- 核验会打开永久链接检查作者、正文和图片。未获取链接时保持待核验；用户可提供本次帖子的链接，不自动重复提交。

## 真实页面检查

使用用户在 media-post 内登录的账号，只读验证了个人主页「张一库」和公共主页「观察世界」的发现、身份切换与恢复，以及两类空白编辑器的正文、图片和发帖按钮。没有填写测试正文、上传图片或提交真实帖子。

Facebook 已在真实账号上发过帖。其他平台的编辑器流程已接入，不能用离线测试代替线上发布成功。

## 自动验证

单元测试覆盖内容类型、SQLite、队列、防重复、崩溃恢复、桌面状态和通知；UI 测试覆盖草稿、标签页、设置、目标选择和确认前不提交；Electron 集成测试覆盖双会话隔离、Facebook 图文发布、素材快照、登录暂停恢复及核验不重发。日常验证跑 `pnpm run test:unit` 和 `pnpm run test:ui`。

集成测试按文件串行运行，避免多个 Electron 窗口争抢 macOS 焦点与全局快捷键。无额外 Chromium 下载。打包仍为当前 arm64 macOS 未签名本地版本，签名、公证与 Intel 尚未验证。
