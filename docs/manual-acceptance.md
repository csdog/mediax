# macOS 人工验收

版本 0.1.0，当前主机 arm64；Intel、签名和公证尚未验证。

1. 在账号管理打开账号标签页，手动登录；检查账号会话相互隔离并可在重启后恢复。
2. 点击「检查状态」，确认个人主页与可管理公共主页的名称、类型与身份正确，检查后恢复原身份。
3. 导入 Markdown、选择两张图片并移除一张；保存草稿，重启后确认正文和素材恢复。
4. 在内容发布勾选目标，检查预览及确认框。正文为空或没有目标时禁止发布；取消确认框不会创建任务。
5. 以下步骤仅在用户明确授权验收正文、图片和目标后执行：分别向个人主页、公共主页发布正文和图文，打开永久链接核对作者、完整内容与图片。
6. 多目标任务应依次执行并分别记录结果。明确失败可单项重试，成功项不能重发；安全验证时打开账号标签页手动完成后「继续」。
7. 提交结果不确定时只「核验结果」，必要时提供本次真实帖子链接；不能根据提示框或点击完成就标记成功。
8. 删除源图片后，本次任务仍从 task-assets 快照读取；退出、重启后已提交/未知目标不自动重发。
