# macOS 人工验收

开发版本：0.1.0；当前验证机器 arm64。Intel macOS、签名和公证尚未验证。

1. 启动应用，账号管理新增两个账号，分别打开账号窗口。手动登录；检查窗口可调整大小及关闭后重开。此步骤不授权发帖。
2. 导入 Markdown，确认标题、列表、链接、段落转为可编辑纯文本；选两张本地图片，移除其中一张，检查预览。
3. 保存草稿，退出并重开，确认账号、正文和仍可读取的图片恢复。
4. 验证个人主页与可管理 Page 的身份 ID、切换和权限。当前尚未实现，需在用户完成登录后继续开发。
5. 实际发布、失败重试、验证码恢复和永久链接核验尚未实现，不得报告验收通过。完成实现后仅针对用户明确授权的测试内容与目标执行。

现有自动测试：8 项存储/内容/队列单元测试、1 项编辑器 UI 测试、2 项真实 Electron 集成测试。集成测试包含账号与草稿重启、SQLite 原生模块加载和 CDP 双会话隔离；全程不访问 Facebook。
